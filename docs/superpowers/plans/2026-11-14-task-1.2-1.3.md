- Deny, cancel, or choose “approximate location” → app stays alive and explains that precise location is required.

- Screen timeout → the walk window keeps the screen on without a wakelock permission.

```kotlin
package com.randomwalk.app.permission

import android.Manifest
import android.content.Context
import android.content.pm.PackageManager

object LocationPermissionGate {
    const val REQUEST_CODE = 1001
    val REQUIRED_PERMISSIONS = arrayOf(
        Manifest.permission.ACCESS_FINE_LOCATION,
        Manifest.permission.ACCESS_COARSE_LOCATION,
    )

    fun hasPreciseLocation(context: Context): Boolean =
        context.checkSelfPermission(Manifest.permission.ACCESS_FINE_LOCATION) ==
            PackageManager.PERMISSION_GRANTED

    fun hasApproximateLocation(context: Context): Boolean =
        context.checkSelfPermission(Manifest.permission.ACCESS_COARSE_LOCATION) ==
            PackageManager.PERMISSION_GRANTED
}
```

- [x] **Step 3: Replace the placeholder `MainActivity` UI with the gate**

Use a centered vertical `LinearLayout` with `TextView messageView` and `Button actionButton`.

| State | Message | Button |
|---|---|---|
| precise granted | 位置权限已授予 | GONE |
| coarse only | 需要精确位置权限（仅“大致位置”不够） | 重新授权 / 打开系统设置 |
| neither | 需要位置权限才能生成漫步路线 | 重新授权 / 打开系统设置 |

Behavior:
- On first creation (`savedInstanceState == null`) and no precise permission, call `requestPermissions(REQUIRED_PERMISSIONS, REQUEST_CODE)`.
- Save `permissionRequested` in `onSaveInstanceState` so configuration changes do not re-open the dialog.
- `onRequestPermissionsResult`: an empty `grantResults` counts as denied; update the gate; never throw.
- Button click: if `shouldShowRequestPermissionRationale(ACCESS_FINE_LOCATION)` is true, request again; otherwise open `Settings.ACTION_APPLICATION_DETAILS_SETTINGS` for `package:$packageName`.
- `onResume`: refresh the gate so a permission granted/revoked in system settings is reflected.
- Request-on-launch is temporary for the skeleton; when the 2.x start screen exists, move the request to the “开始漫步” action and keep the helper unchanged.

- [x] **Step 1: Add `ImmersiveMode.kt`**

```kotlin
package com.randomwalk.app.ui

import android.os.Build
import android.view.View
import android.view.Window
import android.view.WindowInsets
import android.view.WindowInsetsController
import android.view.WindowManager

object ImmersiveMode {
    fun enter(window: Window) {
        window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
            window.setDecorFitsSystemWindows(false)
            window.insetsController?.apply {
                hide(WindowInsets.Type.statusBars() or WindowInsets.Type.navigationBars())
                systemBarsBehavior =
                    WindowInsetsController.BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE
            }
        } else {
            @Suppress("DEPRECATION")
            window.decorView.systemUiVisibility =
                View.SYSTEM_UI_FLAG_IMMERSIVE_STICKY or
                View.SYSTEM_UI_FLAG_FULLSCREEN or
                View.SYSTEM_UI_FLAG_HIDE_NAVIGATION or
                View.SYSTEM_UI_FLAG_LAYOUT_FULLSCREEN or
                View.SYSTEM_UI_FLAG_LAYOUT_HIDE_NAVIGATION or
                View.SYSTEM_UI_FLAG_LAYOUT_STABLE
        }
    }

    fun exit(window: Window) {
        window.clearFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
            window.setDecorFitsSystemWindows(true)
            window.insetsController?.show(
                WindowInsets.Type.statusBars() or WindowInsets.Type.navigationBars(),
            )
        } else {
            @Suppress("DEPRECATION")
            window.decorView.systemUiVisibility = View.SYSTEM_UI_FLAG_VISIBLE
        }
    }
}
```
